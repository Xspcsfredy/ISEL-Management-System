# 🏫 ISEL Management System

Academic management system developed for the Object-Oriented Programming (OOP) course during the 1st year of the BSc in Computer Science and Multimedia Engineering at ISEL.

## 📌 Overview
A Java application designed to manage students, faculty, and academic courses at ISEL. The system supports both terminal-based navigation and two distinct Graphical User Interfaces (GUIs).

## 🚀 Key Features
* **Console Mode:** Text-based navigation and core operations via terminal.
* **GUI Mode:** Interactive visual interface featuring custom buttons and navigation options.
* Object-oriented data management and association across multiple academic entities.

## 💻 Tech Stack
* **Language:** Java
* **Paradigm:** Object-Oriented Programming (OOP)
* **GUI Framework:** Swing / JavaFX
